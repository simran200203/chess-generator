# Chess piece graphics — credits & licence

The chess piece images in this directory are the **Cburnett** set, the standard
tournament-style ("Staunton") vector pieces widely used across chess software.

- **Author:** User:Cburnett (Colin M. L. Burnett), Wikimedia Commons
- **Files:** `Chess_klt45.svg`, `Chess_qlt45.svg`, `Chess_rlt45.svg`,
  `Chess_blt45.svg`, `Chess_nlt45.svg`, `Chess_plt45.svg` (light pieces) and
  `Chess_kdt45.svg`, `Chess_qdt45.svg`, `Chess_rdt45.svg`, `Chess_bdt45.svg`,
  `Chess_ndt45.svg`, `Chess_pdt45.svg` (dark pieces).

## Source

Each file was downloaded from Wikimedia Commons, e.g.:

- https://commons.wikimedia.org/wiki/File:Chess_klt45.svg
- https://commons.wikimedia.org/wiki/File:Chess_kdt45.svg

(substitute the file name above for the other ten pieces).

## Modification

Only the **fill colours** were changed to match this project's palette
(light pieces `#F1E6D0`, dark pieces `#211817`); the original outline strokes
are unchanged. No geometry was altered.
